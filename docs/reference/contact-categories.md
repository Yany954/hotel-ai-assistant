# Contact categories (closed set)

Extracted from the hotel's existing contact sheet. Add new organizations under these categories;
propose a new category here (as a doc change, reviewed) rather than inventing one ad hoc in code.

- `tech_support` — e.g. Tech Guru (wifi/internet)
- `third_party_platform` — Expedia, Booking, Wyndham Rewards
- `property_management_company` — CLC (multiple phone lines: accounting, checkin certified,
  contracts, ecommerce, main, fax, after-hours)
- `reservation_platform` — Hotel Engine (has account number)
- `internal_staff` — e.g. Sales contact
- `sister_hotel` — Hampton Inn, Red Roof Inn, TRU (Fort Mill)
- `vendor_supply` — Coke, Southern Glazer's, Golden Malted, B&B (beer), juice machine service
- `phone_system_vendor` — Intech (has named operations contact)
- `elevator_service` — TK
- `maintenance_emergency` — plumber (boiler tanks), system/property support
- `safety_security` — Safe Passages, local police
- `emergency_services` — fire department — see docs/requirements/escalation-procedures.md for
  the mandatory hard override; never treated as a plain lookup
